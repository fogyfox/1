# 12. Основной механизм безопасности в операционной системе Linux:
- ✓ ***разрешения определяют доступ к этому файлу для владельца файла, для других членов группы владельца файла и для всех прочих пользователей.***
- заимствование прав клиента и привилегии клиента.
- ✓ ***файл получает UID и GID создающего его процесса.***
- системный список управления доступом.
- ✓ ***определяется три вида доступа: чтение, запись и исполнение файла.***
- ✓ ***процесс несет на себе UID и GID своего владельца.***
- ✓ ***файл получает набор разрешений доступа, определяемых создающим процессом.***
